**IMPORTANTE - Relação Sector/Chefe:**
- Cada Sector tem um `chefe` (ForeignKey para User) obrigatório
- Cada Sector pode ter um `chefe_substituto` (ForeignKey opcional) para ausências
- O método `get_chefe()` retorna o chefe atual (chefe_substituto se chefe estiver inativo)
- O método `get_colaboradores()` retorna todos os utilizadores do sector
- O método `get_subordinados()` retorna colaboradores + chefes de sectores subordinados

**IMPORTANTE - Sectores Especiais:**
- Recomenda-se criar sectores especiais durante a configuração inicial:
  - "Gabinete do PCA" ou "Presidência" - onde o PCA (is_pca=True) é o chefe
  - "Secretaria" - setor responsável pela receção e distribuição de documentos
- Estes sectores têm papéis especiais no fluxo de documentos (ver apps entrada/saida)

**IMPORTANTE - Fluxo de Estados de Documentos:**
Fluxo principal de entrada:
1. **Recebido** - Documento entra (Secretaria/Portal/Quiosque)
2. **Encaminhado** - Automático para PCA ou para chefe de sectou ou para funcionario
3. **Em Tratamento** - Utilizador está a processar o documento
4. **Concluído** - Trabalho finalizado (notifica PCA se foi de sector)
5. **Arquivado** - Documento finalizado definitivamente
6. **Devolvido** - (Opcional) Sector devolve ao PCA para reanálise

Regras de transição:
- Recebido → Encaminhado (automático para PCA)
- Encaminhado → Em Tratamento (quando alguém começa a tratar)
- Em Tratamento → Concluído → Arquivado (fluxo normal)
- Em Tratamento → Devolvido (sector devolve ao PCA)
- Qualquer estado → Arquivado (PCA pode arquivar diretamente)

**IMPORTANTE - Sistema de Notificações:**

Interface:
- **Navbar**: Badge com contador (🔔 5) + Dropdown com últimas 5 notificações
- **Página dedicada**: /notificacoes/ com todas as notificações, filtros e paginação
- **Marcação automática**: Ao clicar na notificação, marca como lida e vai ao documento

Funcionalidades:
- ✅ Navegação direta ao documento relacionado
- ✅ Preview do assunto na mensagem
- ✅ Marcar individualmente como lida
- ✅ Marcar todas como lidas (botão)
- ✅ Indicador visual (lida/não lida)
- ✅ Ícones por tipo de notificação
- ✅ Prioridade (urgente = vermelho, normal = azul)
- ✅ Data relativa ("Há 5 minutos", "Ontem")
- ✅ Histórico completo com paginação

Eventos que geram notificações:
- Documento novo criado → Notifica PCA
- Documento encaminhado → Notifica destinatário
- Documento concluído → Notifica PCA (se veio de sector)
- Documento devolvido → Notifica PCA ou Chefe
- Mensagem interna → Notifica destinatário

**IMPORTANTE - Sistema de Despachos/Pareceres/Comentários:**

O sistema permite adicionar **Despachos, Pareceres e Comentários** aos documentos durante o encaminhamento:

**Tipos e Permissões:**
- **DESPACHO**: Decisão administrativa
  - ✅ PCA pode criar
  - ✅ Chefe de Sector pode criar
  - ❌ Colaborador NÃO pode criar

- **PARECER**: Opinião técnica/jurídica
  - ✅ PCA pode criar
  - ✅ Chefe de Sector pode criar
  - ❌ Colaborador NÃO pode criar

- **COMENTÁRIO**: Observação simples
  - ✅ PCA pode criar
  - ✅ Chefe de Sector pode criar
  - ✅ Colaborador pode criar

**Funcionalidades:**
- Cada despacho/parecer/comentário pode ter **anexos**
- Podem ter **visibilidade controlada**: Todos | Apenas Chefes e PCA | Apenas PCA
- Autor pode **editar** até 24h após criação
- Campo **editado** indica se foi modificado
- Histórico completo de todos os despachos no documento
- Notificações quando despacho/parecer é adicionado

**Fluxo de Encaminhamento com Despacho:**
1. Utilizador abre documento
2. Clica "Encaminhar"
3. Seleciona destinatário (sector/utilizador)
4. OPCIONAL: Adiciona Despacho/Parecer/Comentário
5. OPCIONAL: Anexa ficheiros ao despacho
6. OPCIONAL: Define visibilidade
7. Submete encaminhamento
8. Sistema cria MovimentacaoDocumento + DespachoDocumento (se adicionado)
9. Destinatário recebe notificação com preview do despacho
